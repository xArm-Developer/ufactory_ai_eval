The Four Closed-Loop Execution Phases

为了克服 AA-Robotics v0.1 榜单中各模型常见的“单目透视误差导致空抓（36%–45% 成功率）”与“抓取角部导致滑脱”，我们将每次任务拆解为四个严密的物理与视觉闭环阶段：

  • 1. Coarse Vision & Border Check (Z=205mm)

    Goal:
    在初始位姿 (317.2, -118.6, 200.0) 检测红块 HSV 轮廓质心与 minAreaRect 角度。
    Calibration:
    目标中心 (663.5, 496.5)，比例尺 (2.659, 2.713) px/mm；若处视野边缘则居中复测（如 Run 20）。

  • 2. Near-Field Visual Servoing (Z=110/75mm)

    Goal:
    下降至方块正上方 Z=110/75mm 悬停，二次采样消除单目高处透视视差。
    Precision:
    目标像素 (663.5, 496.5)，分辨率 ~5.5 px/mm，19 次平均闭环微调修正 8.93 mm。

  • 3. Yaw Alignment & Grasp (Z=6mm)

    Goal:
    自适应旋转末端偏航角 Yaw (-35.5° ~ +42.3°) 对齐方块平行边，下降至 Z=6mm 闭合夹爪。
    Pass criteria:
    夹爪闭合反馈 gpos 稳定在 256–295（均值 268.4），抬升至 Z=240mm 无滑脱。

  • 4. Box Placement & Home Return

    Goal:
    平移至纸箱中心 (320.0, 270.0, 240.0)，下降至 Z=190.0mm 张开夹爪释放方块并回零。
    Pass criteria:
    红块完全落入纸箱内部，机械臂归位至 (317.2, -118.6, 200.0)，双相机快照确认。

三方块叠放四阶段闭环执行流程

为了克服多层 31 mm 方块叠放中常见的“前序叠块干扰”、“夹爪黄色防滑贴纸误检”、“旋转偏心扫落”与“二层塔顶累积偏移”，我们将每次叠塔任务拆解为四个严密的物理与视觉闭环阶段：

  • 1. 全局三色扫描与拆塔检测 (Z=205mm)

    目标：
    在 Z=205mm 结合三维深度门控 165 < dep < 385 同步提取红、黄、绿三块木块的 HSV 轮廓质心与初始偏航角。
    自动拆解策略：
    若任意两块水平间距 < 28mm 或二层高度异常（z_mm ≈ 300mm），自动触发 STEP 0 在 Z=35.9mm 先拆解平放至桌面空位。

  • 2. 底层绿块基准锁定 (Z=82mm 双通精修)

    目标：
    平移下降至绿块正上方 Z=82mm 进行两轮视觉伺服对齐，消除单目高空视差并锁定底层方塔基准 (green_x, green_y, green_yaw)。
    闭环精度：
    以硅胶垫物理闭合中心 (14.0, 67.0) mm 为基准，双通精修残差收敛至 < 0.5 mm，并屏蔽视野底部夹爪防滑贴纸干扰。

  • 3. 中层黄块叠放与二层塔顶复核 (Z=38/106mm)

    目标：
    双通精定位抓取黄块（gpos ∈ [266, 277]），对齐 green_yaw 缓降至绿块上方 Z=38.0mm 释放，保角纯垂直抽离至 Z=106mm。
    塔顶二次复核：
    在 Z=106mm 对二层黄块顶面执行二次 RGB-D 复核，实测并消除 R3 (-3.1, +2.8mm) 与 R4 (+1.3, +2.8mm) 的放置微小偏移。

  • 4. 顶层红块四边齐平叠放 (Z=69.0mm)

    目标：
    双通精定位抓取红块，对准复核后的二层黄块中心 (tower2_x, tower2_y, tower2_yaw) 缓降至 Z=69.0mm 张爪释放。
    通过标准：
    保角垂直抬升脱离后归位至 (317.2, -118.6, 205.0)，红/黄/绿三层约 93mm 方塔四边齐平稳立，D405 与 D555 双机位核验通过。

柔性抹布对折四阶段闭环执行流程

为了克服柔性织物操作中常见的“背景反光导致的轮廓偏斜”、“高空提拉拖拽底层织物”、“宽开度捏合导致的聚拢起皱”与“双层误夹”，我们将每次抹布对折任务拆解为四个严密的物理与视觉闭环阶段：

  • 1. 四角特征提取与中线解算 (Z=250mm)

    目标：
    在俯视位姿 (300, -100, 250) 结合色差掩码（r>90 & b>195 & g-r<85）与深度中值 (364.8mm) 锁定 BL/BR/TL/TR 四角。
    中线对齐：
    滤除顶部背景绿垫反光，精准解算近端中点 (284.0, -73.2) 与远端中点 (470.4, -85.2)，横向偏差控制在 |ΔY| = 12.0 mm 以内。

  • 2. 近端中点窄开度微捏合与提拉校验 (Z=-1.8mm)

    目标：
    沿对折方向内偏 14mm 至 (298.0, -73.2)，以 gpos=240–250 窄开度（或逐毫米 J2 力矩触碰检测）下探捏合单层布边。
    提拉校验：
    垂直微抬至 Z=38mm 时 D405 最近深度达 153.8mm，确认单层抓稳、无宽开度抽皱且未误夹双层。

  • 3. 低空零张力 7 段圆弧对折 (Z_peak=46mm)

    目标：
    以折痕中线 (377.2, -79.2) 为轴、R=79.2mm 为半径，沿 Z_peak=46.0mm 低空 7 段圆弧平滑翻转至远端 (452.4, -85.2, Z=4.0mm) 释放。
    零张力控制：
    严格满足 Z_peak < R 几何约束，避免高弧线（如 R1 Z=82mm）悬链线张力拖走底层抹布，实现底布零位移。

  • 4. 3D 深度分层角部微调展平 (Z=9.5mm)

    目标：
    利用 D405 深度图识别左远角高出桌面 20.5mm 的三层内折凸起 (408.0, -20.0, d=344.3mm)，在 Z=9.5mm 仅捏住第 3 层向外翻展至 (458.0, +10.0)。
    通过标准：
    抹布呈平整 ~110–118×180–195 mm 双层 2:1 矩形，四角齐平无卷曲，机械臂安全归位。

桌面翻骰子五阶段闭环执行流程

为了克服刚体骰子微操作中常见的“侧面点数遮挡”、“深度阴影导致的抓取偏心”、“腕部倾转线缆碰撞”与“高空松爪弹跳滚偏”，我们将每次翻筛子任务拆解为五个严密的物理与视觉闭环阶段：

GPT-6 Astra 第 4 轮（5 → 3）五阶段双相机标准执行流程实拍（点击可切换至顶部大图）

  • 1. 初始检测与偏航对齐 (initial)

    目标：
    D405 识别顶面点数（5点）与侧面朝向，通过颜色+深度联合分割消除深度阴影。
    闭环对齐：
    平均修正 0.99–9.80 mm 定位偏差，解算平行边抓取偏航角 Yaw=-120.14°。

  • 2. 平行边夹取与微抬校验 (lifted)

    目标：
    下探至 (388.26, -165.43, Z=16.3mm) 正交闭合夹爪并垂直微抬至 Z=25mm。
    夹持验证：
    校验 SDK 编码器读数 gpos ∈ [353, 372]（R4 gpos=355），排除空抓（gpos≈149）与滑脱。

  • 3. 高空安全倾转 90° (tilted)

    目标：
    先抬升至安全高度 Z=120–140mm，再执行腕部俯仰倾转（Pitch -60° 或 -45°→+45°）。
    防碰撞策略：
    避免低空直接大角度旋转导致 D405 相机外壳或 USB 线缆刮蹭桌面。

  • 4. 最低点间隙拟合松爪 (released)

    目标：
    从 Z=50mm 分段缓降至 Z=30mm（或 Z=14mm），实时重拟合骰子最低点离桌间隙。
    防滚偏释放：
    当最低点间隙收敛至 6.61–7.26 mm 时微张夹爪（gpos=547），确保骰子贴桌平稳落定不弹跳。

  • 5. 双相机点数核验归位 (final)

    目标：
    沿倾转反方向安全退刀并撤回初始位姿 (317.2, -118.6, 200.0) mm。
    通过标准：
    腕部 D405 与全局 Insta360 Link 2C 共同确认顶面点数精确减 2（5→3、6→4 或 3→1）。
